# TV Home Universal 0.2.0 Preview

## New

- Choose Classic or Horizontal layout from Settings. The choice is saved and app order is shared.
- Horizontal scrolling keeps the selected app at the second slot from the third app onward, with cards clipped inside the glass panel.
- Watch Timer: choose 1–240 minutes and see a minimal remaining-time overlay while watching.
- A liquid glass 30-second countdown appears before sleep, with Sleep and Cancel buttons over a dark translucent background.
- Watch Timer is beside Screensaver in Quick Settings.
- Timer menus follow English / Indonesian system language.

## Improvements

- Return from Settings to the last selected app in Horizontal mode.
- Entrance animations run only for initially visible cards.
- Carousel movement stops while the launcher is not visible.

## Requirements and preview status

Launcher: Android TV / Google TV 8.0+. Watch Timer: Android 9+, enabled TV Home accessibility, and Alarms & reminders permission on Android 12+ where required. Firmware determines sleep/overlay behavior. Timer cancels on manual screen off or reboot.

Build, signature verification and host logic checks passed. This universal build has not been tested on physical TVs. Keep the stock launcher enabled while testing.

Update by installing the APK over 0.1.1; the application ID and development signing key are unchanged. No private API keys or signing keys are included in the source bundle. Third-party audio notices remain applicable.
