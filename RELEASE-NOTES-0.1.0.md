# TV Home Universal 0.1.0 Preview

First public preview of the universal fork, targeting Android TV / Google TV 8.0+.

## Included

- Liquid glass launcher menus and quick settings.
- Five favourite apps, automatic app discovery, and remote app reordering.
- Optional greeting, clock/date and prayer widgets.
- Online wallpaper integrations and bundled offline gradients.
- Animated screensaver with a moving clock and rotating backgrounds.
- Optional accessibility Home override and system UI sounds.

## Preview status

The APK builds, its signature verifies, and host logic checks pass. This universal version has not been tested on physical TVs. Home selection, accessibility, input shortcuts, sleep and settings access vary by firmware.

Console sound samples from the private build are not included. Power opens the native power menu rather than privileged shutdown. Keep the stock launcher enabled while testing.

This is a development-signed preview, not a production release. Application ID: `io.github.tvhome.universal`.

Attach the APK and checksum file to this release, and mark it as a pre-release. See README for installation, compatibility and privacy details.
