# Upload 0.2.0

1. Extract TV-Home-Universal-0.2.0-update-files.zip.
2. Open the extracted folder and drag its contents into Add file → Upload files at the repository ROOT. Keep the launcher, tests and tools folder structure. Existing matching paths will be updated.
3. Commit as: Update to 0.2.0 preview: layouts and Watch Timer.
4. Create a new release with tag v0.2.0, target main, title TV Home Universal 0.2.0 Preview, and the supplied release notes.
5. Attach the 0.2.0 APK, full source ZIP and SHA256SUMS-0.2.0.txt. The checksum file lists these exact APK and full source ZIP names.
6. Mark as pre-release and publish when ready. Keep the older release available.

The changed-files archive excludes unchanged audio and screenshots to stay below the browser's 100-file upload limit. The complete source archive is for a fresh checkout or release attachment; use the smaller update archive to update the existing repository.
