# Privacy

No project analytics SDK is included. Preferences, app order, greeting and wallpaper credentials stay in private app storage. Android app backup is disabled. API credentials have no separate application-level encryption; never share app data.

Online wallpaper providers receive content requests and credentials when needed. Aladhan receives the city, region and country entered for prayer times. Each provider has its own privacy policy. Bundled gradient images require no provider account.

Optional accessibility override handles window identity and remote key events without reading node text. Location permission is used for Wi-Fi scan/SSID visibility subject to Android policy. No automatic package disabling or device administration is included.

Watch Timer stores its chosen duration, boot count and elapsed-time deadline in private preferences. It schedules a local alarm and uses the enabled accessibility service for timer overlays and the lock-screen action. No timer usage data is sent to a server.
